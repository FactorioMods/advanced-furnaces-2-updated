# Advanced Furnaces 2 SpaceAgeFix: Updated

Five furnace tiers with crafting speeds matched to faster transport belts.

**Factorio 2.1 · Version 1.0.3**

- Configurable energy use.
- Optional loader integration.

## Installation

Disable Load-Furn-2-SpaceAgeFix before enabling this fork. Use the same startup settings on every multiplayer peer.
